This note proves that Subset Sum can be solved in time $O(2^{0.4877n})$, in the model and with the guarantees of
OpenAI result \#138, ``Subset Sum in Time $O(2^{0.49n})$'' (OpenAI, 4 October 2026). We call that work \emph{the paper}.
References such as ``Lemma 2.3'' or ``(4.11)'' point to the paper. Appendix B restates, without proof, every result,
definition and equation of the paper that this note uses, under the paper's numbering. We rely on the paper's proofs of
these results and do not repeat them. With Appendix B, this note can be read without the paper.

The algorithm keeps the paper's framework: isolation, a capped preliminary search, a modular checksum, and the
subtraction of aliases. We replace two of its parts. A new alias step (Theorem A) works with a smaller modulus, and a
family of 43 checksum filters (Theorem B) uses that smaller modulus. Section 1.2 lists the numerical checks.

\section*{1. The result}\addcontentsline{toc}{section}{1. The result}

\textbf{Theorem 1.} There is a uniform randomized classical algorithm for Subset Sum with the following properties in the
word-RAM model of the paper (word length (1.1)). For every input with $n \ge 2$, it halts on every execution and
answers correctly with probability at least $2/3$. For every fixed positive integer $c$, there are constants $C_c > 0$
and $N_c \ge 2$ such that every input with $n \ge N_c$ and $b \le n^c$ is processed in at most $C_c\,2^{0.4877n}$
word operations, on every outcome of the random choices. The program does not depend on $c$.

Here $b$ is the largest bit length of the input integers and the target, as in the paper. The intermediate bound is
\[2^{(\tau_0 + 20\epsilon)n + O(n^{0.7})}\,\mathrm{poly}(n+b+2),\qquad \tau_0 = 0.48769,\quad \epsilon = 10^{-8}.\]
Since $\tau_0 + 20\epsilon = 0.4876902 < 0.4877$, the gap absorbs every factor $2^{O(n^{0.7})}\mathrm{poly}(n+n^c)$.

The new alias step has five features.

\begin{enumerate}
\item One random partition $[n] = M \cup L \cup R$ with a large block, $|M| \approx 0.473n$. It stays fixed for all trials.
\item The value maps of $L$ and $R$ (distinct values with summed phases) are built once.
\item The trials repeat about $2^{\hat F}$ times. Here $\hat F$ is a sampled estimate of $-\log\mathbb E_V 2^{-d(V)}$
over random $(|M| - 2k)$-subsets $V$ of $M$.
\item In each trial, the right masks are grouped into classes with equal reduced and unreduced weights.
\item Coverage uses Corollary D, an averaged form of the small-layer property.
\end{enumerate}

A large block gives each alias many representations, so the alias step works with a large prime of only $0.51613n$
bits. The checksum costs $2^{\tau_0 n}$ with $\tau_0 = \eta - \Delta$. At this $\eta$, the filter family certifies the
budget $\Delta = 0.02844$, so $\tau_0 = 0.48769$.

\section*{3. An averaged small-layer lemma}\addcontentsline{toc}{section}{3. An averaged small-layer lemma}

Let $w$ be integer weights on a finite index set; equal weights are allowed. For a finite index set $V$ and $j \ge 0$,
put
\[\Sigma_j(V) = \{w(T) : T \subseteq V,\ |T| = j\},\qquad a_j(V) = |\Sigma_j(V)|\Big/\binom{|V|}{j},\]
and $\Sigma(V) = \bigcup_j\Sigma_j(V)$, $d(V) = |V| - \log|\Sigma(V)|$.

\textbf{Lemma 3.1 (covering).} Let $0 \le k \le t \le |V|$, and let $W$ be a uniform $(t-k)$-subset of $V$. Then
$a_t(V) \le \mathbb E_W\, a_k(V\setminus W)$.

\emph{Proof.} For each $x \in \Sigma_t(V)$, fix a $t$-set $T_x \subseteq V$ with $w(T_x) = x$. Consider the pairs $(x, W)$ with
$W \subseteq T_x$ and $|W| = t - k$. The map $(x, W) \mapsto (W, x - w(W))$ is injective, because
$x = (x - w(W)) + w(W)$. Its second coordinate is $w(T_x\setminus W) \in \Sigma_k(V\setminus W)$. There are
$\binom tk|\Sigma_t(V)|$ pairs, so
\[\binom tk\,|\Sigma_t(V)| \le \sum_{W\subseteq V,\ |W| = t-k}|\Sigma_k(V\setminus W)|.\]
Divide by $\binom{|V|}{t}\binom tk = \binom{|V|}{t-k}\binom{|V| - t + k}{k}$. $\square$

\textbf{Lemma 3.2 (sampling).} Let $k \le s \le |V|$, and let $S$ be a uniform $s$-subset of $V$. Then
$\mathbb E_S\, a_k(S) \ge a_k(V)$.

\emph{Proof.} For each $x \in \Sigma_k(V)$, fix a $k$-set $K_x$ with $w(K_x) = x$. Then $x \in \Sigma_k(S)$ whenever
$K_x \subseteq S$. This event has probability $\binom{|V|-k}{s-k}\big/\binom{|V|}{s} = \binom sk\big/\binom{|V|}{k}$.
Sum over $x$ and divide by $\binom sk$. $\square$

\textbf{Lemma 3.3 (a good layer).} Some $t$ with $2t \le |V|$ has $|\Sigma(V)| \le (|V|+1)\,|\Sigma_t(V)|$. In particular
$a_t(V) \ge 2^{-d(V)}/(|V|+1)$.

\emph{Proof.} The $|V| + 1$ layers cover $\Sigma(V)$, so some layer $j$ has $|\Sigma_j(V)| \ge |\Sigma(V)|/(|V|+1)$.
Complementation gives $\Sigma_{|V|-j}(V) = w(V) - \Sigma_j(V)$, so we may take $t = \min(j, |V| - j)$. Finally
$\binom{|V|}{t} \le 2^{|V|}$. $\square$

\textbf{Corollary D (averaged small layer).} Let $M$ be a finite index set with integer weights. Let $k, \sigma, v$ be
integers with $2k \le \sigma$, $2\sigma \le v + 2k$, $v \le |M|$ and $\binom\sigma k\binom vk \le 2^v$. Let $S$ be a
uniform $\sigma$-subset and $V$ a uniform $v$-subset of $M$. Then
\[\mathbb E_S\, a_k(S) \;\ge\; \frac{\mathbb E_V\, 2^{-d(V)}}{v+1}.\]

\emph{Proof.} The hypotheses give $k \le \sigma \le v$. Fix a $v$-set $V \subseteq M$, and let $S_V$ be a uniform
$\sigma$-subset of $V$. We show that $2^{-d(V)}/(v+1) \le \mathbb E\, a_k(S_V)$. Take $t$ from Lemma 3.3.

\emph{Case $t \ge k$.} Lemma 3.1 gives $a_t(V) \le \mathbb E_W\, a_k(V\setminus W)$, where
$|V\setminus W| = v - t + k \ge v/2 + k \ge \sigma$. Lemma 3.2 for $V \setminus W$ and $s = \sigma$ gives
$a_k(V\setminus W) \le \mathbb E\, a_k(S')$ for a uniform $\sigma$-subset $S'$ of $V\setminus W$. When $W$ is uniform,
$S'$ is a uniform $\sigma$-subset of $V$. Hence $2^{-d(V)}/(v+1) \le a_t(V) \le \mathbb E\, a_k(S_V)$.

\emph{Case $t < k$.} Then $t < k \le v/2$, so $|\Sigma_t(V)| \le \binom vt \le \binom vk$. Lemma 3.3 gives
$2^{v - d(V)} \le (v+1)\binom vk$. With the hypothesis, $2^{-d(V)}/(v+1) \le \binom vk2^{-v} \le 1/\binom\sigma k$.
Every $\sigma$-set $S$ has $a_k(S) \ge 1/\binom\sigma k$, because $\Sigma_k(S)$ is not empty.

Finally average over $V$. A uniform $\sigma$-subset of a uniform $v$-subset of $M$ is a uniform $\sigma$-subset of $M$.
$\square$

\textbf{Remark.} Signs do not change $d$ (F2), but they change $a_k$. Theorem A applies Corollary D to one fixed signing of
the block for each alias (Lemma A5, Step 2).

\section*{4. The preliminary search}\addcontentsline{toc}{section}{4. The preliminary search}

\textbf{Proposition P.} Run the procedure of Proposition 2.4 with the list cap $B_n = 2^{\lceil\tau_0 n\rceil}$ in place of
$2^{\lceil 0.489985n\rceil}$. It returns the correct decision or CONTINUE. On every execution it uses at most
$2^{\tau_0 n}\,\mathrm{poly}(n+b+2)$ word operations. If $\mathbb E\, d(V) > (\tfrac12 - \tau_0 + \zeta)n$ for a uniform
$\lfloor n/2\rfloor$-subset $V$, it returns CONTINUE with probability $O(1/n)$.

\emph{Proof.} Correctness and the time bound are those of Proposition 2.4. An answer comes from two complete lists, and
every merge stops after $O(B_n)$ steps. Let $U$ be either side of the random split; it has $\lfloor n/2\rfloor$ or
$\lceil n/2\rceil$ elements. Since $f$ is nondecreasing, $\mathbb E\, d(U) > (\tfrac12 - \tau_0 + \zeta)n$. Lemma 2.3 gives
$\mathrm{Var}\, d(U) \le n$, and Chebyshev's inequality gives
\[\Pr\big[d(U) < (\tfrac12 - \tau_0 + \tfrac\zeta2)n\big] \le \frac{n}{(\zeta n/2)^2} = \frac{4}{\zeta^2n}.\]
Otherwise $\log|\Sigma(U)| = |U| - d(U) \le \tfrac n2 + \tfrac12 - (\tfrac12 - \tau_0 + \tfrac\zeta2)n < \tau_0 n$ for
$n > 1/\zeta$. Then both lists fit under the cap, and the search decides. The sampler of the split fails with
probability at most $n2^{-n^2}$. $\square$

So, for fixed tie weights, either the preliminary search decides with probability $1 - O(1/n)$, or
\[\mathbb E_{V\subseteq[n],\ |V| = \lfloor n/2\rfloor}\, d(V) \;\le\; (\tfrac12 - \tau_0 + \zeta)\,n. \tag{LD}\]
Theorem A uses (LD) only to bound the number of trials and to prove coverage. The algorithm never evaluates it.

\section*{5. Alias phase sums (Theorem A)}\addcontentsline{toc}{section}{5. Alias phase sums (Theorem A)}

Let $P$ be a prime in $[2^{\lfloor\eta n\rfloor}, 2^{1+\lfloor\eta n\rfloor})$ and $b_i = c_i \bmod P \in \{0, \dots, P-1\}$.
The aliases of the target $t_s$ are
\[\mathcal A_s(P) = \{I \subseteq [n] : c(I) \equiv t_s \pmod P,\ c(I) \ne t_s\}.\]
An alias $I$ has $b(I) \equiv t_s \pmod P$ and $0 \le b(I) \le n(P-1)$. So it has a unique \emph{carry}
$q \in \{0, \dots, n-1\}$ with
\[b(I) = T_{s,q} := (t_s \bmod P) + qP.\]

\textbf{Idea.} In a trial, an alias $I$ is represented by every split of the set $S = (I\cap M)\triangle F$ into a left mask $X$
of size $k$ and a right mask $Y$ of size $\sigma - k$. The small prime $P'$ keeps a $1/P'$ fraction of the left
records. So a trial finds $I$ when the left masks of $S$ take about $P'$ distinct values. Corollary D supplies these
values on average over $S$, and $2^{\hat F}$ repeated trials turn the average into coverage of every alias. The
deficiencies pay for the repetitions: $d(L)$ pays on the left side, and $d(M)$ pays on the right side, because the
right masks are grouped by value.

\subsection*{5.1 Statement}

\textbf{Theorem A.} There is a randomized procedure with the following properties for all sufficiently large $n$. Its input is
the transformed weights and targets of (2.1) under the guard of Section 2.2, a prime
$P \in [2^{\lfloor\eta n\rfloor}, 2^{1+\lfloor\eta n\rfloor})$, and phases $\varphi \in (\mathbb Z/P\mathbb Z)^n$. It returns
FAIL or complex numbers $\hat A_s$ for $0 \le s \le nN_0$.

\begin{enumerate}
\item Assume (LD). Let $P$ be uniform among the primes of the interval, and let $\varphi$ be arbitrary; it may depend on $P$.
Then, with probability $1 - o(1)$, the procedure does not fail and
\[\Big|\hat A_s - \sum_{I\in\mathcal A_s(P)}\chi(I)\Big| \le \frac1{16}\qquad\text{for every } s.\]
The $o(1)$ depends only on $n$.
\item On every execution the procedure uses at most $2^{\tau_0 n + 2n^{0.7}}\,\mathrm{poly}(n+b+2)$ word operations.
\end{enumerate}

\subsection*{5.2 The procedure}

The procedure makes its random draws with the bounded samplers of Section 6.2 (F6). For $F \subseteq M$, the signed
weights on $M$ are
\[c^F_i = (-1)^{[i\in F]}c_i,\qquad b^F_i = (-1)^{[i \in F]}b_i\qquad (i \in M).\]
For every $Z \subseteq M$ they satisfy
\[c^F(Z) = c(Z\triangle F) - c(F),\qquad b^F(Z) = b(Z\triangle F) - b(F). \tag{5.1}\]
Indeed $c(Z\triangle F) - c(F) = c(Z\setminus F) + c(F\setminus Z) - c(F) = c(Z\setminus F) - c(Z\cap F)$.

The \emph{key} of a set $A$ is the pair $\kappa(A) = (c(A), b(A)) \in \mathbb Z^2$. For a key $\kappa = (x, y)$ we write
$c(\kappa) = x$ and $b(\kappa) = y$.

\begin{enumerate}
\item \textbf{Partition.} Draw a uniform $m$-subset $M \subseteq [n]$, then a uniform $|L|$-subset $L$ of $[n]\setminus M$. Put
$R = [n]\setminus(M \cup L)$. The partition stays fixed.
\item \textbf{Value maps.} For every $A \subseteq L$, compute $\kappa(A)$ and $\chi(A)$. Sort, and store each distinct key
$\kappa$ once with $\Phi_L(\kappa) = \sum_{A\subseteq L:\ \kappa(A) = \kappa}\chi(A)$. Do the same for $R$.
\item \textbf{Trial count.} Draw $n^2$ independent uniform $v$-subsets $V_1, \dots, V_{n^2}$ of $M$. Compute each $|\Sigma(V_j)|$
exactly by the merge procedure of Proposition 2.4, without a cap. Put
\[\hat S = \frac1{n^2}\sum_{j=1}^{n^2}\frac{|\Sigma(V_j)|}{2^v} = \frac1{n^2}\sum_{j=1}^{n^2}2^{-d(V_j)},\qquad
\hat F = \log\frac1{\hat S} + e_n,\qquad T = n^7\,2^{e_n}\Big\lceil\frac1{\hat S}\Big\rceil,\]
where $e_n$ is an integer with $2n^{0.6} \le e_n \le 2n^{0.6} + 1$. Then $n^72^{\hat F} \le T \le 2n^72^{\hat F}$.
\item \textbf{Trials.} For every target index $s$ and every carry $q \in \{0, \dots, n-1\}$, run $T$ independent trials.
A trial for $(s, q)$ does the following.
\begin{itemize}
\item (a) Draw a uniform $F \subseteq M$. Put $T^F = T_{s,q} - b(F)$ and $t^F = t_s - c(F)$.
\item (b) Draw a uniform prime $P' \in [2^{\lfloor\gamma m\rfloor}, 2^{1+\lfloor\gamma m\rfloor})$ and a uniform
$j' \in \mathbb Z/P'\mathbb Z$.
\item (c) \emph{Left records:} all pairs $(\kappa_L, X)$ with $\kappa_L$ a key of $L$, $X \subseteq M$, $|X| = k$, and
$b(\kappa_L) + b^F(X) \equiv j' \pmod{P'}$. To list them, sort the keys of $L$ by $b(\kappa_L) \bmod P'$; for
each $X$, find the keys with the needed residue by binary search.
\item (d) \emph{Right classes:} list all $Y \subseteq M$ with $|Y| = \sigma - k$, and group them by
$\lambda(Y) = (b^F(Y), c^F(Y))$. A \emph{class} is a value $\lambda = (b_\lambda, c_\lambda)$ that occurs, together with
the list of its members $Y$.
\item (e) \emph{Right class records:} all pairs $(\kappa_R, \lambda)$ with $\kappa_R$ a key of $R$, $\lambda$ a class, and
$b(\kappa_R) + b_\lambda \equiv T^F - j' \pmod{P'}$. List them as in (c).
\item (f) \emph{Matching:} group the right class records by the integer $b(\kappa_R) + b_\lambda$, and sort each group by the
integer $c(\kappa_R) + c_\lambda$. For each left record $(\kappa_L, X)$, find the group with
$b(\kappa_R) + b_\lambda = T^F - b(\kappa_L) - b^F(X)$. In it, find by two binary searches the interval of records
with $c(\kappa_R) + c_\lambda = t^F - c(\kappa_L) - c^F(X)$. Skip that interval, and \emph{visit} every other record of
the group.
\item (g) \emph{Expansion:} for each visited $(\kappa_R, \lambda)$ and each member $Y$ of $\lambda$, test $X \cap Y = \varnothing$.
If the test passes, put $Z = (X\cup Y)\triangle F$, and insert the key $(\kappa_L, \kappa_R, Z)$ into the
dictionary $\mathcal D_s$ unless it is there.
\end{itemize}
\item \textbf{Output.} For each $s$, return $\hat A_s$, a finite-precision value of
$\sum_{(\kappa_L, \kappa_R, Z)\in\mathcal D_s}\Phi_L(\kappa_L)\,\Phi_R(\kappa_R)\,\chi(Z)$, computed as in Section 6.2.
\item \textbf{Cap.} Count the elementary steps of Steps 1--5: subsets enumerated, merge operations, masks listed, keys sorted,
records formed, records visited, members expanded, dictionary operations, terms summed, and trial divisions. Return
FAIL as soon as the count would exceed $2^{\lceil\tau_0 n\rceil + \lceil n^{0.7}\rceil}$. Also return FAIL if a
bounded sampler fails.
\end{enumerate}

Each step costs $\mathrm{poly}(n+b)$ word operations. Keys have $O(b + \log n)$ bits, masks have $m$ bits, and the
dictionaries are balanced search trees. The finite-precision sums use $n^2$ fractional bits (Section 6.2). With the
cap, this proves part 2 of Theorem A. The rest of this section proves part 1.

\subsection*{5.3 Keys, classes and soundness}

For keys $\kappa_L$ of $L$ and $\kappa_R$ of $R$ and a set $Z \subseteq M$, the \emph{class} of $(\kappa_L, \kappa_R, Z)$ is
\[\mathcal C(\kappa_L, \kappa_R, Z) = \{A\cup Z\cup B : A \subseteq L,\ B \subseteq R,\ \kappa(A) = \kappa_L,\ \kappa(B) = \kappa_R\}.\]
Each $I \subseteq [n]$ lies in exactly one class: the class of $(\kappa(I\cap L), \kappa(I\cap R), I\cap M)$. All
members of a class have the same $c(I)$ and the same $b(I)$. So either every member is an alias of $t_s$ or none is.
In the first case we call the class an \emph{alias class} of $t_s$. Since phases add,
\[\sum_{I \in \mathcal C(\kappa_L, \kappa_R, Z)}\chi(I) = \Phi_L(\kappa_L)\,\Phi_R(\kappa_R)\,\chi(Z). \tag{5.2}\]

\textbf{Lemma A1 (soundness).} Every key inserted into $\mathcal D_s$ is an alias class of $t_s$.

\emph{Proof.} An insertion comes from a left record $(\kappa_L, X)$, a visited record $(\kappa_R, \lambda)$, and a member $Y$ of
$\lambda$ with $X \cap Y = \varnothing$; then $Z = (X\cup Y)\triangle F$. Take $A, B$ with $\kappa(A) = \kappa_L$ and
$\kappa(B) = \kappa_R$, and put $I = A\cup Z\cup B$. By (5.1), $b^F(X) + b^F(Y) = b^F(X\cup Y) = b(Z) - b(F)$, and the same
holds for $c$. The group condition gives $b(A) + b(Z) - b(F) + b(B) = T^F$. So $b(I) = T_{s,q}$, and
$c(I) \equiv b(I) \equiv t_s \pmod P$. The skipped interval gives $c(A) + c(Z) - c(F) + c(B) \ne t^F$, so $c(I) \ne t_s$.
Hence $I$ is an alias, and so is every member of its class. $\square$

The alias classes of $t_s$ partition $\mathcal A_s(P)$, and the dictionary holds each key once. So, by (5.2) and
Lemma A1: if $\mathcal D_s$ contains every alias class of $t_s$, then the exact output sum equals
$\sum_{I\in\mathcal A_s(P)}\chi(I)$.

\textbf{Lemma A2 (key and class counts).}

\begin{enumerate}
\item $L$ has at most $(n+1)\,|\Sigma(L)| = (n+1)\,2^{|L| - d(L)}$ keys, and each value $c(\kappa)$ occurs in at most $n+1$
keys. The same holds for $R$.
\item Every trial has at most $(2m+1)\,2^{m - d(M)}$ right classes.
\end{enumerate}

\emph{Proof.} (1) A key $(x, y)$ of $L$ has $y \equiv x \pmod P$ and $0 \le y \le |L|(P-1)$. So $y$ takes at most
$|L| + 1 \le n + 1$ values for each $x$. (2) By (5.1), $c^F(Y) = c(Y\triangle F) - c(F)$ takes at most
$|\Sigma(M)| = 2^{m - d(M)}$ values. For each of them, $b^F(Y) \equiv c^F(Y) \pmod P$ and $|b^F(Y)| < mP$. This leaves at
most $2m+1$ values of $b^F(Y)$. $\square$

\subsection*{5.4 The trial count}

Let $V$ be a uniform $v$-subset of $M$, and put
\[g_M = -\log\mathbb E_V\, 2^{-d(V)},\qquad e_M = \mathbb E_V\, d(V).\]
Jensen's inequality gives $g_M \le e_M$, and (F1) gives $e_M \le d(M)$.

\textbf{Lemma A3.} With probability $1 - o(1)$ over $M$, $L$ and Step 3, the following hold.

\begin{enumerate}
\item $\hat F \ge g_M$.
\item $\hat F \le e_M + 3n^{0.6} + 1 \le d(M) + 3n^{0.6} + 1$.
\item $\hat F \le d(L) + 5n^{0.6} + 1$.
\item Under (LD): $g_M \le e_M \le (\tfrac12 - \tau_0 + \zeta)n + n^{0.6}$ and $\hat F \le (\tfrac12 - \tau_0 + \zeta)n + 4n^{0.6} + 1$.
\end{enumerate}

\emph{Proof.} (1) $\hat S$ is the mean of $n^2$ independent samples of $2^{-d(V)}$, so $\mathbb E\,\hat S = 2^{-g_M}$. Markov's
inequality gives $\hat S < 2^{2n^{0.6}}2^{-g_M}$, except with probability $2^{-2n^{0.6}}$. Then
$\hat F \ge \log(1/\hat S) + 2n^{0.6} > g_M$.

(2) Apply (F3) inside $M$. For fixed $M$, every $d(V_j)$ is at most $e_M + n^{0.6}$, except with probability
$2n^2e^{-n^{0.2}/2}$. Then $\hat S \ge 2^{-e_M - n^{0.6}}$, so $\hat F \le e_M + n^{0.6} + e_n \le e_M + 3n^{0.6} + 1$.
Also $e_M \le d(M)$.

Next we show $e_M \le f(v) + n^{0.6}$ with high probability. Exchange one element $i \in M$ for $j \notin M$. Couple $V$
with $V' = V$ if $i \notin V$, and $V' = (V\setminus\{i\})\cup\{j\}$ otherwise. Then $V'$ is uniform in the new block, and
$|d(V) - d(V')| \le 1$ by (F1). So $e_M$ changes by at most 1 under an exchange. The exposure martingale of $M$ (as in
(F3)) and Azuma's inequality give $e_M \le \mathbb E_M\, e_M + n^{0.6} = f(v) + n^{0.6}$, except with probability
$e^{-n^{0.2}/2}$.

(3) $L$ is a uniform $|L|$-subset of $[n]$. By (F3), $d(L) \ge f(|L|) - n^{0.6}$, except with probability
$2e^{-n^{0.2}/2}$. Since $|L| > v$ (S2) and $f$ is nondecreasing,
$\hat F \le e_M + 3n^{0.6} + 1 \le f(v) + 4n^{0.6} + 1 \le d(L) + 5n^{0.6} + 1$.

(4) $v \le \lfloor n/2\rfloor$ (S2), so $f(v) \le f(\lfloor n/2\rfloor) \le (\tfrac12 - \tau_0 + \zeta)n$ under (LD).
Combine this with the bounds above. $\square$

Let $\mathcal E_3$ be the event of Lemma A3. It depends only on $M$, $L$ and Step 3, which are independent of $P$.

\subsection*{5.5 Reduction modulo $P$ on half blocks}

Call a $\sigma$-subset $S \subseteq M$ \emph{bad} for $P$ if some $\lambda \in \{-1, 0, 1\}^S$ has
$\sum_{i\in S}\lambda_ic_i \ne 0$ and $P \mid \sum_{i\in S}\lambda_ic_i$. Put $\delta = (\eta - \tfrac\mu2\log3)/2$.
Then $\delta > 0.0706$ by (C8).

\textbf{Lemma A4.} For every fixed $M$, with probability $1 - o(1)$ over $P$, at most a $2^{-\delta n}$ fraction of the
$\sigma$-subsets of $M$ are bad.

\emph{Proof.} Fix $S$. There are fewer than $3^\sigma$ vectors $\lambda$. Each nonzero $\sum\lambda_ic_i$ has absolute value
below $2^{b + O(\log n)}$. By (F4) with $L' = \lfloor\eta n\rfloor$, $P$ divides it with probability at most
$\mathrm{poly}(n)(b + \log n)2^{-\eta n}$. So $S$ is bad with probability at most
$\mathrm{poly}(n)(b+\log n)\,3^\sigma2^{-\eta n} \le \mathrm{poly}(n)(b + \log n)\,2^{-2\delta n}$, as $\sigma \le \mu n/2$.
The expected bad fraction has the same bound. By Markov's inequality, the fraction exceeds $2^{-\delta n}$ with
probability at most $\mathrm{poly}(n)(b+\log n)2^{-\delta n}$. This is $o(1)$ by the guard. $\square$

On a good set, reduction modulo $P$ keeps all distinctions between signed subset sums. Precisely: let $S$ be good, let
$\epsilon_i \in \{\pm1\}$ for $i \in S$, and let $X, X' \subseteq S$. Then
\[\sum_{i\in X}\epsilon_ic_i \ne \sum_{i\in X'}\epsilon_ic_i \implies \sum_{i\in X}\epsilon_ib_i \ne \sum_{i\in X'}\epsilon_ib_i. \tag{5.3}\]
The difference of the left sides is $\sum_{i\in S}\lambda_ic_i$ with $\lambda_i = \epsilon_i([i\in X] - [i\in X'])$. It is
not zero, so $P$ does not divide it. The difference of the right sides is congruent to it modulo $P$, so it is not zero.

\subsection*{5.6 Coverage}

\textbf{Lemma A5 (one trial).} Assume (LD), $\mathcal E_3$, and the event of Lemma A4. Fix $s$, an alias $I \in \mathcal A_s(P)$
with carry $q$, and one trial for $(s, q)$. After the trial, $\mathcal D_s$ contains the key of the class of $I$ with
probability at least $2^{-g_M}n^{-6}$. The threshold for $n$ does not depend on $I$, $s$, $P$ or $M$.

\emph{Proof.} Put $A = I\cap L$, $B = I\cap R$ and $S = (I\cap M)\triangle F$.

\emph{Step 1 (half of the block).} $F$ is a uniform subset of $M$, so $S$ is too. Hence $|S| = \sigma$ with probability
$\binom m\sigma2^{-m} \ge 1/(m+1)$. Conditional on this event, $S$ is a uniform $\sigma$-subset of $M$, and
$F = S\triangle(I\cap M)$.

\emph{Step 2 (the signs on $S$ are fixed).} Let $i \in S$. Either $i \in I\setminus F$, and then $c^F_i = c_i$; or
$i \in F\setminus I$, and then $c^F_i = -c_i$. So on $S$ the signed weights equal the weights
\[c^I_i = c_i\ \ (i \in I\cap M),\qquad c^I_i = -c_i\ \ (i \in M\setminus I).\]
These depend on $I$ but not on $S$. The same holds for $b^F$ and $b^I$.

\emph{Step 3 (many layer values).} Apply Corollary D to the weights $c^I$ on $M$, with $k, \sigma, v$ of Section 2.2;
(S1)--(S3) give its hypotheses. By (F2), $d$ is the same for $c^I$ and for $c$. Hence
\[\mathbb E_S\, a_k(S; c^I) \ge \frac{\mathbb E_V\,2^{-d(V)}}{v+1} = \frac{2^{-g_M}}{v+1}.\]
Let $W_S = \{b(A) + b^F(X) : X \subseteq S,\ |X| = k\}$ and $B_S = |W_S|$. If $S$ is good, then (5.3) and Step 2 give
$B_S \ge |\Sigma_k(S; c^I)| = a_k(S; c^I)\binom\sigma k$. Bad sets have probability at most $2^{-\delta n}$. By Lemma
A3(4), $2^{-\delta n} \le 2^{-g_M}/(2(v+1))$, because $\tfrac12 - \tau_0 + \zeta < 0.013 < \delta$. Since $a_k \le 1$,
\[\mathbb E_S\Big[\mathbf 1_{S\ \text{good}}\,\frac{B_S}{\binom\sigma k}\Big] \ge \frac{2^{-g_M}}{v+1} - 2^{-\delta n} \ge \frac{2^{-g_M}}{2(v+1)}.\]

\emph{Step 4 (the small prime keeps many residues).} Fix a good $S$. The set $W_S$ depends on $P$, $M$, $L$, $I$ and $S$, but
not on $P'$ or $j'$. Its elements lie in $(-nP, nP)$, so differences have at most $\eta n + \log n + 3$ bits. For
distinct $x, x' \in W_S$, (F4) with $L' = \lfloor\gamma m\rfloor$ gives $\Pr[P' \mid x - x'] \le K_0n^22^{-\gamma m}$, for
an absolute constant $K_0 \ge 1$. Let $z_y$ be the number of elements of $W_S$ in the residue class $y$ modulo $P'$. Then
\[\mathbb E_{P'}\sum_y z_y^2 \le B_S + K_0n^2B_S^2\,2^{-\gamma m}.\]
If $B_S \le 2^{\gamma m}$, the right side is at most $2K_0n^2B_S$. Otherwise it is at most $2K_0n^2B_S^22^{-\gamma m}$.
By Markov's inequality, with probability at least $1/2$ over $P'$, $\sum_yz_y^2$ is at most twice that bound. Then
the Cauchy--Schwarz inequality $(\sum_yz_y)^2 \le \#\{y : z_y > 0\}\cdot\sum_yz_y^2$ shows that at least
$\min(B_S, 2^{\gamma m})/(4K_0n^2)$ residues are occupied. Since $P' < 2^{1+\gamma m}$, a uniform $j'$ hits an occupied
residue with probability at least
\[\frac{\min(B_S2^{-\gamma m}, 1)}{8K_0n^2} \ge \frac{B_S}{8K_0n^2\binom\sigma k}.\]
The last step uses $B_S \le \binom\sigma k$ and $2^{\gamma m} \le \binom\sigma k$ (S4).

\emph{Step 5 (a hit is recovered).} Suppose $j' \equiv b(A) + b^F(X) \pmod{P'}$ for some $X \subseteq S$ with $|X| = k$. Then the
left record $(\kappa(A), X)$ is listed. Put $Y = S\setminus X$; so $|Y| = \sigma - k$ and $X\cap Y = \varnothing$. Since
$S\triangle F = I\cap M$, (5.1) gives
\[b(A) + b^F(X) + b(B) + b^F(Y) = b(A) + b(B) + b(I\cap M) - b(F) = T_{s,q} - b(F) = T^F.\]
So the class record $(\kappa(B), \lambda(Y))$ has the residue $T^F - j'$. It is listed, and it lies in the group of the
left record. The same computation with $c$ gives the unreduced sum $c(I) - c(F)$. This differs from
$t^F = t_s - c(F)$, because $I$ is an alias. So the record is not in the skipped interval, and it is visited. The
expansion reaches its member $Y$ and inserts $(\kappa(A), \kappa(B), (X\cup Y)\triangle F) = (\kappa(A), \kappa(B), I\cap M)$,
unless the key is already there.

\emph{Step 6 (product).} The draws of $F$, $P'$ and $j'$ are independent. Steps 1--5 give a success probability of at least
\[\frac1{m+1}\cdot\mathbb E_S\Big[\mathbf 1_{S\ \text{good}}\cdot\frac12\cdot\frac{B_S}{8K_0n^2\binom\sigma k}\Big]
\ge \frac{2^{-g_M}}{32K_0n^2(m+1)(v+1)} \ge 2^{-g_M}n^{-6}\]
for all large $n$. $\square$

\textbf{Corollary A6.} Assume (LD), $\mathcal E_3$, and the event of Lemma A4. Then, except with probability $o(1)$, every
alias class of every target is in its dictionary at the end of Step 4.

\emph{Proof.} Condition on $P$, $\varphi$, $M$, $L$ and Step 3. The $T$ trials for a pair $(s, q)$ are independent, and
$T \ge n^72^{\hat F} \ge n^72^{g_M}$ by Lemma A3(1). By Lemma A5, all of them miss a fixed alias with carry $q$ with
probability at most $(1 - 2^{-g_M}n^{-6})^T \le e^{-n}$. There are at most $(nN_0+1)\,2^n$ pairs of a target and a
subset, and $(nN_0 + 1)\,2^ne^{-n} = o(1)$. $\square$

\subsection*{5.7 Expected work}

\textbf{Lemma A7.} Assume (LD) and $\mathcal E_3$. Condition on $M$, $L$ and Step 3, and average over $P$ and the trials; the
phases are arbitrary. Then the uncapped procedure takes in expectation at most
\[(b+2)\,2^{(\tau_0 - \varepsilon_0 + \zeta)n + O(n^{0.6})}\]
steps.

\emph{Proof.} Recall $T \le 2n^72^{\hat F}$, and that there are $O(n^3)$ pairs $(s, q)$. Polynomial factors go into
$2^{O(n^{0.6})}$. We bound each kind of step.

\begin{enumerate}
\item \emph{Value maps and Step 3:} $2^{|L|} + 2^{|R|} + n^22^{v}$ steps. The exponents $l$, $r$ and $\mu(1-2a)$ are below
$\tau_0 - \varepsilon_0$, by (C6) and (C7).
\item \emph{Masks:} each trial lists $\binom mk + \binom m{\sigma-k} \le 2^{h(1/2-a)m + 2}$ masks and sorts them into classes.
By Lemma A3(4) and (S5), the total is $2^{(h(1/2-a)\mu + 1/2 - \tau_0 + \zeta)n + O(n^{0.6})}$. By (C5) the exponent
is below $(\tau_0 - \varepsilon_0 + \zeta)n$.
\item \emph{Small primes:} each trial tests at most $n^3$ candidates, each by at most $2^{\gamma m/2 + 1}$ divisions. The total
is $2^{(1/2 - \tau_0 + \zeta + \gamma\mu/2)n + O(n^{0.6})}$, far below the bound.
\item \emph{Sorting keys by residue:} each trial sorts at most $(n+1)(2^{|L| - d(L)} + 2^{|R|})$ keys. By Lemma A3(3) and (4),
the total is at most $2^{ln + O(n^{0.6})} + 2^{(r + 1/2 - \tau_0 + \zeta)n + O(n^{0.6})}$.
\item \emph{Left records:} for fixed choices other than $j'$, a pair $(\kappa_L, X)$ is listed with probability $1/P'$, and
$1/P' \le 2^{1-\gamma m}$. So a trial lists at most $(n+1)2^{|L| - d(L)}\binom mk2^{1-\gamma m}$ left records in
expectation. With Lemma A3(3), the total is $2^{(l + (h(a) - \gamma)\mu)n + O(n^{0.6})}$. Use (C2).
\item \emph{Right class records:} by Lemma A2, a trial handles at most $(2m+1)2^{m-d(M)}$ classes. It lists at most
$(n+1)2^{|R|}(2m+1)2^{m-d(M)}2^{1-\gamma m}$ class records in expectation. With Lemma A3(2), the total is at most
$2^{(r + (1-\gamma)\mu)n + O(n^{0.6})} + 2^{\mu n + O(n^{0.6})}$. Use (C3), and $\mu < \tau_0 - \varepsilon_0$.
\item \emph{Visits and expansions.} Each expansion step handles one tuple $(\kappa_L, X, \kappa_R, Y)$, where $Y$ is a member of a
visited class record. Call such a tuple \emph{visited}. Fix a trial's $F$ and $P'$. For values $x_L \in \Sigma(L)$ and
$x_R \in \Sigma(R)$ and masks $X, Y$ of sizes $k$ and $\sigma - k$, put
\[D = x_L + c^F(X) + x_R + c^F(Y) - t^F.\]
$D$ does not depend on $P$. A visited tuple with $c(\kappa_L) = x_L$ and $c(\kappa_R) = x_R$ needs three events.
First, $D \ne 0$, because the exact interval is skipped. Second, $P \mid D$, because the reduced weights add to
$T^F \equiv t^F \pmod P$ and $b_i \equiv c_i$. Third, both small-prime conditions hold; given everything else, this
happens for at most one residue $j'$. By (F4), $\Pr_P[P \mid D] \le \mathrm{poly}(n)(b+\log n)2^{-\eta n}$, as
$|D| < 2^{b + O(\log n)}$. By Lemma A2, at most $(n+1)^2$ key pairs share the values $x_L$ and $x_R$. Hence one
trial visits in expectation at most
\[\mathrm{poly}(n)\,(b + \log n)\,2^{|L| - d(L) + |R| - d(R)}\binom mk\binom m{\sigma-k}2^{-\eta n - \gamma m}\]
tuples. With Lemma A3(3) and $d(R) \ge 0$, the total over all trials is
\[(b + \log n)\,2^{(1 - \mu + (h(a) + h(1/2-a) - \gamma)\mu - \eta)n + O(n^{0.6})}.\]
By (C4) the exponent is below $(\tau_0 - \varepsilon_0)n$.
\item \emph{Matching, dictionaries and output:} polynomial work for each left record, each class record, each visited tuple
and each dictionary key.
\end{enumerate}

Every item is at most $(b+2)\,2^{(\tau_0 - \varepsilon_0 + \zeta)n + O(n^{0.6})}$. $\square$

The proof of item 7 averages over $P$, but it does not condition on the event of Lemma A4. Only coverage uses that event.

\subsection*{5.8 Proof of Theorem A}

Part 2 holds by Section 5.2. For part 1, consider these failure events.

\begin{itemize}
\item $\mathcal E_3$ fails: probability $o(1)$, by Lemma A3.
\item The event of Lemma A4 fails: probability $o(1)$. Here $M$ is independent of $P$.
\item Some alias class is missed, given the two events above: probability $o(1)$, by Corollary A6.
\item The cap is reached. By Markov's inequality and Lemma A7, this has probability at most
\[o(1) + \frac{(b+2)\,2^{(\tau_0 - \varepsilon_0 + \zeta)n + O(n^{0.6})}}{2^{\tau_0 n + n^{0.7}}}.\]
The guard gives $b + 2 \le 2^{n/10^6 + 1}$, and $10^{-6} + \zeta < \varepsilon_0$. So this is $o(1)$.
\item A bounded sampler fails. A capped execution makes at most $2^{O(n)}$ draws, so this has probability
$2^{O(n)}(2^{-n^3} + e^{-c_0n^2}) = o(1)$.
\end{itemize}

Outside these events, $\mathcal D_s$ contains every alias class of $t_s$ (Corollary A6) and nothing else (Lemma A1). Then
the exact output sum is $\sum_{I\in\mathcal A_s(P)}\chi(I)$. The evaluation of Section 6.2 computes each phase to error
$2^{-2n^2}$ and rounds each term to $n^2$ fractional bits. The sums $\Phi_L$ and $\Phi_R$ have at most $2^n$ terms, each
dictionary has at most $2^n$ keys, and every modulus is at most $2^n$. So the total error is $2^{-n^2 + O(n)} \le 1/16$
for large $n$. $\square$

\section*{6. The checksum with a filter family (Theorem B)}\addcontentsline{toc}{section}{6. The checksum with a filter family (Theorem B)}

\subsection*{6.1 The family}

The family has $J = 43$ filters $\mathsf f_v = (r_v, s_v, \kappa_v)$, $v = 0, \dots, 42$, with
\[r_v(x) = \sum_{j=1}^8 r_{v,j}\cos jx,\qquad s_v(x) = \sum_{j=1}^8 s_{v,j}\cos jx,\qquad \kappa_v \in [1.02371,\ 1.06368].\]
The coefficients are decimal rationals with at most five digits after the point (Appendix A). For each filter, Section 3 of the paper defines $F_v = 2^{r_v}$, $G_v = 2^{s_v}$, the
densities $f_v$ and $g_v$, their normalized powers $f_{*,v}$ and $g_{*,v}$ with exponent $\kappa_v$, and the functions
$D_v, A_v, E_v$ of (3.2). The paper uses one filter with $\kappa = 1.0315$; here each filter has its own $\kappa_v$. Put
\[u_v = A_v + E_v - D_v,\qquad w_v = 2D_v - A_v - E_v.\]
These functions exist on the continuous circle $\mathbb T$ and, for each $P$, on the finite circle $\mathbb Z/P\mathbb Z$
(F7).

\textbf{Regions.} Put $b_0 = 1$, $b_1 = 1.25$, $b_2 = 1.6$, $b_3 = 2$, $b_4 = 2.6$, $b_5 = 3.5$, $b_6 = 5$, $b_7 = 8$,
$b_8 = 15$ and $b_9 = \infty$. A real number $W$ lies in the region $\rho_0$ if $W \le \Gamma$, and in the region
$\rho_i$ ($1 \le i \le 9$) if $\Gamma b_{i-1} < W \le \Gamma b_i$.

\textbf{Certificate data.} For each filter $v$ and region $\rho$, Appendix C gives a vector $z = z^{(v,\rho)}$ with

\textbf{Lemma B1 (finite circle).} There is an absolute $P_0$ with the following property. For all $P \ge P_0$ and every

\subsection*{6.2 The construction}

The checksum procedure is the one of the paper's Section 4, with $\tau = \tau_0$ and $\eta = 0.51613$, and with three
changes.

\begin{enumerate}
\item \textbf{Patterns.} For each block $B_j$ and each filter $v$, a frequency's pattern records rational approximations
$D_{v,j}, A_{v,j}, E_{v,j}$ of the block averages of $D_v, A_v, E_v$ at its coordinates. They follow the paper's
rounding rule, so each has error at most $\epsilon$, and $D_{v,j} \ge 0$, $A_{v,j} \le D_{v,j}$, $E_{v,j} \le D_{v,j}$.
The collection $\mathcal P$ of all such blockwise tuples has $Q_n = 2^{O(\sqrt n)}$ elements, since $J$ is fixed. For
$\pi \in \mathcal P$, put $(D_{v,\pi}, A_{v,\pi}, E_{v,\pi}) = \frac1n\sum_jd_j(D_{v,j}, A_{v,j}, E_{v,j})$,
$U_{v,\pi} = A_{v,\pi} + E_{v,\pi} - D_{v,\pi}$ and $W_{v,\pi} = 2D_{v,\pi} - A_{v,\pi} - E_{v,\pi}$.
\item \textbf{Filter choice.} For $\pi\in\mathcal P$, let $v^*(\pi)$ be the least index $v$ that maximizes $U_{v,\pi}$.
\item \textbf{Tables.} For a pattern $\pi$ with $v = v^*(\pi)$, run the paper's construction with filter $v$. That is, $\alpha_\pi$
and $H_\pi$ come from (4.8) with $(D_\pi, A_\pi, E_\pi, U_\pi, W_\pi) := (D_{v,\pi}, A_{v,\pi}, E_{v,\pi}, U_{v,\pi}, W_{v,\pi})$.
The table counts are $R_j = 2^{\lceil(\alpha_\pi D_{v,j} + 4\epsilon)d_j\rceil}$. The scores are $\log f_{*,v}$ and
$\log g_{*,v}$, and the thresholds are $\alpha_\pi A_{v,j} - 3\epsilon$ and $\alpha_\pi E_{v,j} - 3\epsilon$. The pattern
is summed directly if $\alpha_\pi U_{v,\pi} \ge \Delta$. Otherwise it is sampled with $N = 2^{\lceil\tau_0 n\rceil}$
draws.
\end{enumerate}

Multiplicities, caps, sampling and the finite-precision arithmetic do not change.

Lemma 4.2 holds for this construction with $U_\pi := U_{v^*(\pi),\pi}$. Its proof treats one pattern at a time, with one
filter. Part (i) uses only that the pattern of $k$ records the block averages at the $x_i(k)$ for the filter of that
pattern. Parts (ii) and (iii) use only (4.5), (4.8), (4.9), the normalization of $f_{*,v}$ and $g_{*,v}$, and the joint
moment (4.14). These hold for every filter.

\subsection*{6.3 Domination and the error bound}

Let $\mathcal G$ be the event of Lemma 4.2(iii). For a frequency $k$, put $x_i = x_i(k)$, and let $\bar u_l$ and $\bar w_l$
be the averages of $u_l$ and $w_l$ over the coordinates $x_1, \dots, x_n$. As in (4.21), the pattern $\pi$ of $k$
satisfies, for every filter $l$,
\[|U_{l,\pi} - \bar u_l| \le 3\epsilon,\qquad |W_{l,\pi} - \bar w_l| \le 4\epsilon. \tag{6.1}\]

\textbf{Lemma B2 (domination).} Let $\pi$ be a sampled pattern, $v = v^*(\pi)$, and $\rho$ the region of $W_{v,\pi}$. Let $z$ and
$G$ be the certificate data for $(v, \rho)$. Then every frequency $k$ of pattern $\pi$ satisfies
\[-\alpha_\pi U_{v,\pi} \le -\Delta + \frac1n\sum_{i=1}^nz\cdot G(x_i) + 6\epsilon\sum_tz_t.\]

\emph{Proof.} Let $\bar G = \frac1n\sum_iG(x_i)$. Let $G^\pi$ be the same rows with $\bar u_v$, $\bar w_v$ and $\bar u_l$ replaced
by $U_{v,\pi}$, $W_{v,\pi}$ and $U_{l,\pi}$. Each row is affine in at most two of these quantities, with coefficients of
absolute value at most 1 ($a_\Gamma < 1$). By (6.1), $|\bar G_t - G^\pi_t| \le 6\epsilon$ for every row $t$. In detail,
the rows have errors at most $3\epsilon$, $4\epsilon$, $6\epsilon$, $(4a_\Gamma + 3)\epsilon$, $4\epsilon$ and $4\epsilon$.

The rows $t \ge 1$ have $G^\pi_t \ge 0$. The rows $\Gamma - W$, $W - \Gamma b_{i-1}$ and $\Gamma b_i - W$ are nonnegative,
because $W_{v,\pi}$ lies in the region $\rho$. The rows $U_{v,\pi} - U_{l,\pi}$ are nonnegative, because $v$ maximizes
$U_{\cdot,\pi}$. Since $z \ge 0$,
\[z\cdot\bar G \ge z_0G^\pi_0 - 6\epsilon\textstyle\sum_tz_t.\]

\emph{Region $\rho_0$.} Here $W_{v,\pi} \le \Gamma$, so $\alpha_\pi = 1$. Sampling means $U_{v,\pi} < \Delta$. Then
$G^\pi_0 = \Delta - U_{v,\pi} > 0$ and $z_0 \ge 1$ give $-U_{v,\pi} = -\Delta + G^\pi_0 \le -\Delta + z_0G^\pi_0$.

\emph{Region $\rho_i$, $i \ge 1$.} Here $W_{v,\pi} > \Gamma b_{i-1} \ge \Gamma$. So $\alpha_\pi = \Gamma/W_{v,\pi} < 1/b_{i-1} \le z_0$,
and $\alpha_\pi a_\Gamma W_{v,\pi} = \Delta$. Sampling means $\alpha_\pi U_{v,\pi} < \Delta$, that is,
$G^\pi_0 = a_\Gamma W_{v,\pi} - U_{v,\pi} > 0$. Then $-\alpha_\pi U_{v,\pi} = -\Delta + \alpha_\pi G^\pi_0 \le -\Delta + z_0G^\pi_0$.

In both cases, combine with the display above. $\square$

\textbf{Lemma B3 (one sampled pattern).} Let $\pi$ be a sampled pattern and $\rho$ a target residue, and let $E_{\pi,\rho}$ be the
error of the ideal estimate for $\pi$. Then $\mathbb E\big[\mathbf 1_{\mathcal G}|E_{\pi,\rho}|^2\big] \le 2^{-0.00017n + 2}$
for all large $n$.

\emph{Proof.} Put $c_z = 6\sum_tz_t \le 2511$. By (4.11), (4.4) and Lemma B2, every $k < P$ satisfies
\[\mathbf 1_{\mathcal G}\mathbf 1_{\{\mathrm{pattern}(k) = \pi\}}\,L_\pi\,|J_\rho(k)|^2 \le
2^{(\eta - \Delta + (18 + c_z)\epsilon)n}\prod_{i=1}^nM(x_i(k))^2\,2^{z\cdot G(x_i(k))}.\]
The right side does not depend on the pattern or on $\mathcal G$. For fixed $k$, the $x_i(k)$ are independent and uniform
on $\mathbb Z/P\mathbb Z$ under the original phase law. So Lemma B1 bounds the expectation of the right side by
$2^{(\eta - \Delta + (18 + c_z)\epsilon)n}\,2^{(\eta - 0.0002)n}$. As in (4.25), take the expectation of (4.20) and sum over
the $P$ frequencies:
\[\mathbb E\big[\mathbf 1_{\mathcal G}|E_{\pi,\rho}|^2\big] \le \frac{2^{(2\eta - \Delta + (18 + c_z)\epsilon - 0.0002)n}}{NP}
\le 2^{((18 + c_z)\epsilon - 0.0002)n + 2}.\]
The last step uses $N \ge 2^{\tau_0 n}$, $P \ge 2^{\eta n - 2}$ and $\eta - \Delta - \tau_0 = 0$. Finally
$(18 + c_z)\epsilon < 2.6\cdot10^{-5}$. $\square$

\subsection*{6.4 Theorem B}

\textbf{Theorem B.} Fix a constant $d > 0$. There is a uniform randomized procedure with the following properties for all
sufficiently large $n$. Its inputs are an integer $P$ with $|\log P - \eta n| \le 2$, residues $b_1, \dots, b_n$ modulo
$P$, phases $\varphi_1, \dots, \varphi_n$, and a list $\mathcal T$ of at most $n^d$ target residues. It returns FAIL or
estimates $\hat V_\rho$, $\rho \in \mathcal T$, of
\[V_\rho = \sum_{I\subseteq[n]:\ b(I)\equiv\rho\ (\mathrm{mod}\ P)}\chi(I).\]
If the phases are independent and uniform, then with probability $1 - o(1)$ over the phases and the procedure's own
draws, it does not fail and $|\hat V_\rho - V_\rho| \le 1/8$ for every $\rho \in \mathcal T$. The $o(1)$ is uniform in
$P$, the residues and $\mathcal T$. On every execution the procedure uses at most
$2^{(\tau_0 + 20\epsilon)n + O(\sqrt n)}\,\mathrm{poly}(n + |\mathcal T|)$ word operations.

\emph{Proof.} This is Theorem 4.1 with new constants, a filter family, and phases given as input. The paper's proof applies
with these changes.

\begin{itemize}
\item \emph{Sections 4.1--4.3.} Use the construction of Section 6.2 above; Lemma 4.2 holds, as explained there. The paper's
procedure draws the phases itself. Its analysis uses only that the phases are uniform, independent, and independent
of the tables and the samples. This holds here.
\item \emph{Section 4.4.} Direct patterns are exact on $\mathcal G$, as before. For sampled patterns, Lemma B3 replaces
(4.24)--(4.25). Cauchy--Schwarz over the $Q_n = 2^{O(\sqrt n)}$ patterns gives
$\mathbb E\big[\mathbf 1_{\mathcal G}|\sum_\pi E_{\pi,\rho}|^2\big] \le Q_n^2\,2^{-0.00017n + 2}$. Markov's inequality and a
union bound over $\mathcal T$ show that, with probability $1 - o(1)$, $\mathcal G$ holds and every ideal estimate has
error at most $1/16$.
\item \emph{Section 4.5.} Resources and precision do not change. The pattern of a frequency needs $3Jq$ approximate block
averages; Lemma B1 computes each in polynomial time. The arithmetic error is at most $1/16$. $\square$
\end{itemize}

\section*{7. Proof of Theorem 1}\addcontentsline{toc}{section}{7. Proof of Theorem 1}

\textbf{The algorithm.}

\begin{enumerate}
\item If $n < n_*$ or $10^6\lceil\log(b+1)\rceil > n$, run the exact meet-in-the-middle fallback of Section 6.3, and stop.
\item Draw the tie weights, and form $c_i$ and $t_s$ by (2.1).
\item Run the preliminary search of Proposition P. If it decides, return its answer.
\item Draw the prime $P$ uniformly from $[2^{\lfloor\eta n\rfloor}, 2^{1+\lfloor\eta n\rfloor})$ (Section 6.2). Draw independent
uniform phases $\varphi_1, \dots, \varphi_n \in \mathbb Z/P\mathbb Z$, and retain them. Put $b_i = c_i \bmod P$.
\item Run the procedure of Theorem A on $(c, t, P, \varphi)$. If it fails, return NO.
\item Run the procedure of Theorem B on $(P, b, \varphi)$ with the target residues $t_s \bmod P$. If it fails, return NO.
\item For each $s$, put $\hat B_s = \hat V_{t_s\bmod P} - \hat A_s$. Return YES if $|\hat B_s| \ge 1/2$ for some $s$, and NO
otherwise. The test compares the sum of the squares of the dyadic real and imaginary parts with $1/4$.
\end{enumerate}

\textbf{Correctness.} Since $b_i \equiv c_i \pmod P$, the sum $V_{t_s\bmod P}$ runs over the subsets with
$c(I) \equiv t_s \pmod P$. So for every $s$,
\[V_{t_s\bmod P} - \sum_{I\in\mathcal A_s(P)}\chi(I) = B_s := \sum_{I:\ c(I) = t_s}\chi(I).\]
Fix the tie weights. If (LD) fails, Proposition P decides with probability $1 - O(1/n)$. If (LD) holds, Theorem A gives
$|\hat A_s - \sum_{\mathcal A_s(P)}\chi| \le 1/16$ for all $s$ with probability $1 - o(1)$. Its success event depends only
on $P$ and its own draws, not on the phases. For every fixed $P$, Theorem B gives $|\hat V_\rho - V_\rho| \le 1/8$ for all
targets, with probability $1 - o(1)$ over the phases and its own draws. As in the paper, the main procedures also draw
their randomness when the preliminary search decides; then a union bound composes the three statements. So, except with
probability $o(1)$, either the preliminary answer is returned, or $|\hat B_s - B_s| < 1/4$ for all $s$.

In the second case the decision is correct, as in Section 6.3. On a NO instance every $B_s$ is $0$, by Lemma 2.1. On a
YES instance, with probability at least $11/12$ some $t_s$ has exactly one representing subset, and then $|B_s| = 1$. All
$o(1)$ terms depend only on $n$, so a fixed cutoff $n_*$ gives success probability at least $5/6$. Below $n_*$ and when the
guard fails, the fallback is exact.

\textbf{Running time.} Take an execution with $n \ge n_*$ that passes the guard.

\begin{itemize}
\item Tie weights and the transformation: $\mathrm{poly}(n+b)$.
\item Proposition P: $2^{\tau_0 n}\,\mathrm{poly}(n+b+2)$.
\item The prime $P$: at most $n^3$ candidates, each tested by trial division in $2^{\eta n/2 + O(1)}\,\mathrm{poly}(n)$.
\item Theorem A: $2^{\tau_0 n + 2n^{0.7}}\,\mathrm{poly}(n+b+2)$.
\item Theorem B: $2^{(\tau_0 + 20\epsilon)n + O(\sqrt n)}\,\mathrm{poly}(n)$, as there are $O(n^2)$ targets.
\end{itemize}

So the total is at most $K_0\,2^{(\tau_0 + 20\epsilon)n + 2n^{0.7}}(n+b+2)^K$ for fixed constants $K_0$ and $K$. Fix $c$.
For large $n$, every $b \le n^c$ passes the guard, and
\[K_0\,2^{0.4876902n + 2n^{0.7}}(n + n^c + 2)^K = O_c(2^{0.4877n}).\]
The address-space argument of Section 6.3 applies unchanged: the logarithm of the operation count is
$0.4877n + O(\log(n+b+2))$, which is below the word length $w$. The fallback halts on every input and is exact. $\square$

\subsection*{8.2 The 430 region integrals}

The script of Appendix D.2 follows the method of the paper's Appendix A (see B.5). It uses $N = 8192$ quadrature nodes, the inner
strip half-width $\sigma = 0.45$, the outer strip half-width $2\beta = 0.38$, and 200-bit precision. For each filter
$(r, s, \kappa)$ it does the following.

\begin{enumerate}
\item \textbf{Node values.} For $x_k = 2\pi k/N$, Arb computes $r(x_k)$, $s(x_k)$, $F(x_k) = 2^{r(x_k)}$ and $G(x_k) = 2^{s(x_k)}$.
\item \textbf{Normalizers.} $Z_f = \int F$ lies in $T_N(F) + [-e, e]$ with $e = 2B_0/(e^{N\sigma} - 1)$ and $B_0 = 2^{R}$,
$R = \sum_j|r_j|\cosh(j\sigma)$. This is the analytic trapezoid bound (A.6) of B.5 with $N$ nodes in place of 64, because
$|F| \le 2^{R}$ on the strip $|\mathrm{Im}\,z| \le \sigma$. The same holds for
$Z_g$, $Z_{f,\kappa} = \int F^\kappa$ and $Z_{g,\kappa}$.
\item \textbf{Convolutions.} The script encloses $\mathcal P(x) = \int F(x+w)G(w)\,dw$ and
$\mathcal Y(x) = \int F(x+w)G(w)\,(r(x+w) + s(w))\,dw$ at all nodes. The trapezoid sums are exact cyclic correlations,
computed by Arb polynomial products. The error bounds use $B_0 = 2^{R_r + R_s}$ and $(R_r + R_s)2^{R_r + R_s}$.
\item \textbf{Scores.} Put $L = \log\mathcal P - \log(Z_fZ_g)$, $B = \mathcal Y/\mathcal P - \log(Z_fZ_g)$ and
$H = \log Z_{f,\kappa} + \log Z_{g,\kappa} - \kappa\log(Z_fZ_g)$. The identities (A.2) give $D = B - L$,
$u = L + (\kappa-1)B - H$ and $w = (2-\kappa)B - 2L + H$. So the resulting balls contain the exact values $u(x_k)$ and
$w(x_k)$.
\item \textbf{Outer strip.} As in the paper's Appendix A.4 (see B.5), on the strip $|\mathrm{Im}\,z| \le 2\beta$: let $r_\beta$ have the coefficients
$r_j\cosh(j\beta)$, and put $A_f = \int2^{2r_\beta}/Z_f^2$; define $A_g$ in the same way. Then
$q_0 = \sqrt{(A_f-1)(A_g-1)}$ bounds $|Q - 1|$, and
$q_b = \sqrt{A_fA_g}\,\big(\sum_j|r_j|\cosh(j\beta) + \sum_j|s_j|\cosh(j\beta) + |\log(Z_fZ_g)|\big)$ bounds $|QB|$.
All 43 filters have $q_0 < 0.677$. Then $|\mathrm{Re}\,L| \le -\log(1 - q_0)$ and $|B| \le q_b/(1-q_0)$. These
give bounds $U^*$ on $|\mathrm{Re}\,u|$ and $W^*$ on $|\mathrm{Re}\,w|$.
\end{enumerate}

For each certificate $(v, \rho)$, the script averages the node values of $M^22^{z\cdot G}$. On the outer strip, the real
part of each row is at most the matching combination of $\Delta$, $\Gamma$, $b_i$, $U^*$ and $W^*$. With
$|M(z)^2| \le 2 + 2\cosh2\beta$, this bounds the integrand by some $B_0$. The outer error is at most
$2B_0/(e^{2\beta N} - 1)$, which is below $10^{-300}$ for every certificate. The script checks that the average plus the
error is below $2^\eta$. It also asserts $z \ge 0$ and the condition on $z_0$.

The trapezoid bound needs analyticity on a neighborhood of the closed strip. The inner integrands are entire. For the
outer integrand, the bounds hold with $q_0 < 1$ strictly; so one can apply the bound on the strip of half-width
$0.38 - \delta$ for a small $\delta > 0$. This changes the error term by a negligible amount.

\section*{Appendix B. Results used from the paper}\addcontentsline{toc}{section}{Appendix B. Results used from the paper}

The paper is: OpenAI, \emph{Subset Sum in Time $O(2^{0.49n})$}, 4 October 2026 (OpenAI result \#138). This appendix restates,
without proof, everything of the paper that this note uses. It keeps the paper's numbering, so ``Lemma 2.3'' in the body
means Lemma 2.3 below. We rely on the paper's proofs of these statements. Where a statement depends on the paper's
constants, we state it in the general form that the paper's proof gives; the note points out each such use.

\subsection*{B.1 Model, isolation and deficiency (paper, Sections 1--2)}

\textbf{Model (1.1).} An instance has positive integers $a_1, \dots, a_n$ ($n \ge 2$) and a target $t \ge 0$; equal integers
and the empty subset are allowed. Let $b = \max\{1, \lceil\log(1 + \max\{t, a_1, \dots, a_n\})\rceil\}$. The machine is a
word RAM with word length $w = \lceil 4(n + b + \log(n+2))\rceil$. Unit-cost operations act on a constant number of
words: reads and writes, indirect addressing, comparisons, addition, subtraction, multiplication, quotient and
remainder, Boolean operations and shifts. A fresh uniform random word costs one operation. Randomness is one-way: a
random word can be reused only if the program stored it. The program is one fixed program for all $n$ and $b$, with no
advice.

\textbf{Theorem 1.1 (paper).} The statement of our Theorem 1 with $0.49$ in place of $0.4877$.

\textbf{Transformation (2.1).} Let $N_0$ be the power of two with $12n \le N_0 < 24n$. Draw independent uniform
$u_i \in \{1, \dots, N_0\}$, and put
\[C = 1 + nN_0,\qquad c_i = Ca_i + u_i,\qquad t_s = Ct + s\quad (0 \le s \le nN_0).\]
These integers have $O(b + \log n)$ bits, and there are $O(n^2)$ targets.

\textbf{Lemma 2.1 (isolation).} For every choice of the $u_i$: some $I$ has $a(I) = t$ if and only if some $s$ and $I$ have
$c(I) = t_s$. If the instance has a solution, then with probability at least $11/12$ some $t_s$ has exactly one subset
$I$ with $c(I) = t_s$.

\textbf{Deficiency (2.2).} For integer weights and $V \subseteq [n]$: $\Sigma(V) = \{c(I) : I\subseteq V\}$ and
$d(V) = |V| - \log|\Sigma(V)|$.

\textbf{Lemma 2.2.} For arbitrary integer weights: $d(\varnothing) = 0$ and $d(V) \ge 0$. For $i \notin V$,
$0 \le d(V\cup\{i\}) - d(V) \le 1$. For disjoint $U, V$, $d(U\cup V) \ge d(U) + d(V)$. If $V, V'$ have equal size and
differ by the exchange of one index, then $|d(V) - d(V')| \le 1$.

\textbf{Lemma 2.3.} Let $V_q$ be a uniform $q$-subset of $[n]$. Then $\mathrm{Var}\,d(V_q) \le q$, and $\mathbb E\,d(V_q)$ is
nondecreasing in $q$. The proof exposes an ordered sample $X_1, \dots, X_q$ and shows that the Doob martingale
$M_r = \mathbb E[d(\{X_1, \dots, X_q\}) \mid X_1, \dots, X_r]$ has increments of absolute value at most 1. The same proof
applies to a uniform $q$-subset of any fixed finite ground set, and to any set function that changes by at most 1 under
the exchange of one element. (Our (F3) adds Azuma's inequality to this martingale bound.)

\textbf{Proposition 2.4 (capped preliminary search).} The procedure: choose a uniform $\lfloor n/2\rfloor$-subset $V$ by
bounded rejection sampling. For each of the two sides $V$ and $[n]\setminus V$, build the sorted list of distinct subset
sums by inserting one index at a time: merge the current list with its translate by $c_i$ and remove duplicates. Stop
with CONTINUE as soon as a list exceeds the cap $B_n$. If both lists finish, check for every $s$ whether two entries sum
to $t_s$, by a linear scan, and return YES exactly when this happens. The procedure returns the correct decision or
CONTINUE, and it runs in $O(B_n)\,\mathrm{poly}(n + b + 2)$ time on every execution. The paper uses
$B_n = 2^{\lceil 0.489985n\rceil}$ and proves: if $\mathbb E\,d(V) > 0.01004n$, then CONTINUE has probability $O(1/n)$.
Our Proposition P uses another cap and threshold, with the same proof (given in Section 4).

\textbf{Lemma 2.5 (random-prime collisions).} There are absolute constants $K$ and $L_*$ with this property. Let $L' \ge L_*$,
and let $p$ be uniform among the primes in $[2^{L'}, 2^{L'+1})$. If $D \ne 0$ is an integer with $|D| < 2^B$ and
$B \ge 1$, then $\Pr[D \equiv 0 \pmod p] \le KBL'2^{-L'}$.

\subsection*{B.2 The filter functions (paper, Section 3)}

Let $\mathbb T = \mathbb R/2\pi\mathbb Z$ with normalized measure. Let $f, g$ be strictly positive continuous probability
densities on $\mathbb T$, and $\kappa > 0$. Put
\[Q(x) = \int_{\mathbb T}f(x+w)g(w)\,dw,\qquad K_x(w) = \frac{f(x+w)g(w)}{Q(x)},\qquad
f_* = \frac{f^\kappa}{\int f^\kappa},\qquad g_* = \frac{g^\kappa}{\int g^\kappa}. \tag{3.1}\]
\[D(x) = \int K_x\log K_x,\quad A(x) = \int K_x(w)\log f_*(x+w)\,dw,\quad E(x) = \int K_x(w)\log g_*(w)\,dw,\]
\[u = A + E - D,\qquad v = 2D - A - E. \tag{3.2}\]
(This note writes $w$ for the paper's $v$.) These are relative entropies, so
\[D \ge 0,\qquad D - A \ge 0,\qquad D - E \ge 0. \tag{3.3}\]
The paper's filter takes trigonometric polynomials $r(x) = \sum_j r_j\cos jx$ and $s(x) = \sum_j s_j\cos jx$, puts
$F = 2^r$, $G = 2^s$, $f = F/\int F$ and $g = G/\int G$, and uses fixed constants $\kappa$, $r_j$, $s_j$. Its
Proposition 3.1 proves two moment bounds (3.6) for these constants; this note replaces them by Proposition B.

\textbf{Finite circle.} For an integer $P \ge 2$, identify $j \in \mathbb Z/P\mathbb Z$ with the angle $2\pi j/P$. Replace
every integral above, including all normalizers, by the average $P^{-1}\sum_{j=0}^{P-1}$.

\textbf{Lemma 3.2 (finite filtering data).} There is an integer $P_0$ such that for $P \ge P_0$ the finite-circle functions
satisfy (3.3) and the finite form (3.7) of the moment bounds. The absolute values of $D, A, E, u, v, \log f_*, \log g_*$ and
$\log K_x(w)$ are bounded independently of $P$. For each fixed rational $\rho > 0$, one fixed deterministic procedure
approximates each of these quantities to error $\rho$ in time polynomial in $\log P$, without a sum over the $P$ points.
The proof uses only that $r$ and $s$ are fixed trigonometric polynomials: the finite functions converge uniformly to the
continuous ones, and Riemann sums converge for the outer integrals.

\subsection*{B.3 The checksum (paper, Section 4)}

Fix $\tau$ and $\eta$ and put $\Delta = \eta - \tau$, $\Gamma = 2\tau - \eta$, $a_\Gamma = \Delta/\Gamma$ and
$\epsilon = 10^{-8}$. Let $M(x)^2 = 2 + 2\cos x$.

\textbf{Theorem 4.1 (modular checksum estimator).} Fix $d > 0$. There is a uniform randomized procedure with the following
guarantee for large $n$. Its input is an integer $P$ with $|\log P - \eta n| \le 2$, residues $b_1, \dots, b_n$ modulo $P$,
and at most $n^d$ target residues $\rho \in \mathcal T$. It draws and keeps uniform phases $\varphi_i$, and returns FAIL or
estimates $\hat V_\rho$ of $V_\rho = \sum_{I:\ b(I)\equiv\rho}e_P(\sum_{i\in I}\varphi_i)$. With probability $1 - o(1)$,
uniformly in $P$, the residues and $\mathcal T$, it does not fail and $|\hat V_\rho - V_\rho| \le 1/8$ for all
$\rho \in \mathcal T$. Every execution takes $2^{(\tau + 20\epsilon)n + O(\sqrt n)}\mathrm{poly}(n + |\mathcal T|)$
operations. The paper proves this for its constants; Theorem B is our version.

The construction and the facts we use are these.

\begin{itemize}
\item \textbf{Fourier form (4.3)--(4.4).} $V_\rho = P^{-1}\sum_{k=0}^{P-1}J_\rho(k)$ with
$J_\rho(k) = e_P(-k\rho)\prod_{i=1}^n(1 + e_P(x_i(k)))$ and $x_i(k) = \varphi_i + kb_i \bmod P$. So
$|J_\rho(k)|^2 = \prod_iM(x_i(k))^2$. For fixed $k$ and uniform independent phases, the $x_i(k)$ are independent and
uniform.
\item \textbf{Blocks and patterns (4.5)--(4.6).} Partition $[n]$ into $q = \Theta(\sqrt n)$ blocks $B_j$ of sizes
$d_j = \Theta(\sqrt n)$. A frequency's pattern records, for each block, rational approximations $D_j, A_j, E_j$ of the
block averages of $D, A, E$ at its coordinates $x_i(k)$, each with error at most $\epsilon$, on a fixed grid, rounded so
that $D_j \ge 0$, $A_j \le D_j$, $E_j \le D_j$ (4.5). The set $\mathcal P$ of all such grid tuples has
$Q_n = 2^{O(\sqrt n)}$ elements (4.6). For $\pi \in \mathcal P$: $(D_\pi, A_\pi, E_\pi) = \frac1n\sum_jd_j(D_j, A_j, E_j)$,
$U_\pi = A_\pi + E_\pi - D_\pi$ and $W_\pi = 2D_\pi - A_\pi - E_\pi$.
\item \textbf{Parameters (4.8)--(4.9).} $\alpha_\pi = 1$ if $W_\pi \le \Gamma$ and $\alpha_\pi = \Gamma/W_\pi$ otherwise;
$H_\pi = \tau - \alpha_\pi(D_\pi - A_\pi)$. Then $\Delta \le H_\pi \le \tau$ and
$\eta - H_\pi + \alpha_\pi(D_\pi - E_\pi) = \Delta + \alpha_\pi W_\pi \le \tau$.
\item \textbf{Digits.} $B_\pi = 2^{\lceil(\eta - H_\pi)n\rceil}$. High digits $0 \le h < \lceil P/B_\pi\rceil$ give vectors
$y_i(h) = \varphi_i + hB_\pi b_i$; low digits $0 \le \ell < B_\pi$ give $z_i(\ell) = -\ell b_i$. The pair $(h, \ell)$
represents $k = hB_\pi + \ell$, and $y_i(h) - z_i(\ell) = x_i(k)$.
\item \textbf{Tables (4.7).} Block $B_j$ gets $R_j = 2^{\lceil(\alpha_\pi D_j + 4\epsilon)d_j\rceil}$ independent tables. Each
coordinate of a table has label $*$ with probability $1 - \alpha_\pi$, and otherwise a uniform $\theta \in \mathbb Z/P\mathbb Z$.
A label $\theta$ gives the high score $\log f_*(y_i - \theta)$ and the low score $\log g_*(z_i - \theta)$; a label $*$
gives 0. Fixed approximations to error $\epsilon$ replace the scores. A vector passes a block table if its average
score is at least $\alpha_\pi A_j - 3\epsilon$ (high side) or $\alpha_\pi E_j - 3\epsilon$ (low side). A whole table is
a tuple of one block table per block; an entry is a digit with a whole table that it passes; a match is a high entry
and a low entry with the same whole table. $L_\pi$ is the number of matches.
\item \textbf{Lemma 4.2.} (i) Conditional on any phases, with probability $1 - o(1)$ every $k < P$ has a match in its own pattern.
(ii) In each pattern, both entry counts have expectation at most $2^{(\tau + 8\epsilon)n + O(\sqrt n)}$, and
$\mathbb E L_\pi \le 2^{(\eta - \alpha_\pi U_\pi + 12\epsilon)n + O(\sqrt n)}$ (4.10). (iii) With probability $1 - o(1)$,
all frequencies are covered and, in every pattern, both entry counts are at most $2^{(\tau + 14\epsilon)n}$ and
\[L_\pi \le 2^{(\eta - \alpha_\pi U_\pi + 18\epsilon)n}. \tag{4.11}\]
Call this event $\mathcal G$. The proof of (ii) uses the joint moment
$\mathbb E_{\varphi,\text{tables}}2^{S_h + S_\ell} = 1$ (4.14) for the total scores of a digit pair and a table tuple.
\item \textbf{Multiplicity (4.16).} $\mu_\pi(k)$ is the number of matches of $k$ in pattern $\pi$; it is computed exactly by
retesting the block tables. Entry lists are capped at $C_n = 2^{\lceil(\tau + 20\epsilon)n\rceil}$ (4.17).
\item \textbf{Estimation.} If $\alpha_\pi U_\pi \ge \Delta$, the procedure enumerates all matches and adds
$J_\rho(k)/(P\mu_\pi(k))$ for each match with $k < P$ and pattern $\pi$ (4.18); on $\mathcal G$ this is exact. Otherwise
it averages $N = 2^{\lceil\tau n\rceil}$ independent uniform matches, each with value $L_\pi J_\rho(k)/(P\mu_\pi(k))$ if
$k < P$ has pattern $\pi$ and 0 otherwise (4.19). Given the phases and tables on $\mathcal G$, this is unbiased, and its
mean square error is at most
\[\frac1N\,\frac{L_\pi}{P^2}\sum_{k < P:\ \mathrm{pattern}(k) = \pi}|J_\rho(k)|^2. \tag{4.20}\]
\item \textbf{Pattern errors (4.21).} For a frequency of pattern $\pi$, with $\bar u, \bar v$ the coordinate averages of $u, v$ at
the $x_i(k)$: $|U_\pi - \bar u| \le 3\epsilon$ and $|W_\pi - \bar v| \le 4\epsilon$.
\item \textbf{Error bound (4.24)--(4.25).} The paper proves
\[\mathbf 1_{\mathcal G}\mathbf 1_{\{\mathrm{pattern}(k)=\pi\}}L_\pi|J_\rho(k)|^2 \le
2^{(\eta - \Delta + O(\epsilon))n}\prod_iM(x_i(k))^2\,2^{R(x_i(k))}\]
with its two functions $R$. It takes the expectation
over the phases, and uses its moment bounds to get $\mathbb E[\mathbf 1_{\mathcal G}|E_{\pi,\rho}|^2] \le 2^{-0.0007n}$.
Then Cauchy--Schwarz over the $Q_n$ patterns, Markov's inequality and a union bound over $\mathcal T$ give total ideal
error at most $1/16$ with probability $1 - o(1)$. Our Lemmas B2 and B3 replace this step.
\item \textbf{Resources (Section 4.5).} Caps bound the work on every execution; the finite-precision arithmetic of Section 6.2
adds error at most $1/16$.
\end{itemize}

\subsection*{B.4 Implementation and the main proof (paper, Section 6)}

\begin{itemize}
\item \textbf{Bounded draws (6.2).} A uniform draw from $\{0, \dots, q-1\}$ uses rejection on $\lceil\log q\rceil$ random bits, and
fails after $n^3$ rejections (probability at most $2^{-n^3}$). A prime in $[2^h, 2^{h+1})$ is drawn by testing at most
$n^3$ uniform candidates by trial division; conditional on success it is uniform among the primes, and failure has
probability at most $e^{-c_0n^2}$. Coupled with ideal samplers, all capped executions differ from ideal ones with
probability $o(1)$.
\item \textbf{Complex sums (6.2).} Each phase is computed to error $2^{-2n^2}$ with dyadic parts, each weighted term is rounded to
$n^2$ fractional bits, and the sums are exact. With $2^{O(n)}$ terms of size $2^{O(n)}$, the total error is
$2^{-n^2 + O(n)}$.
\item \textbf{Decision and composition (6.1, 6.3).} $\hat B_s$ is the checksum estimate minus the alias phase sum; the answer is
YES if some $|\hat B_s| \ge 1/2$. Any failure of a main procedure gives NO. The main procedures draw their randomness
even when the preliminary search decides, so a union bound composes the success events.
\item \textbf{Fallback (6.3).} Below a fixed cutoff $n_*$, or when the input guard fails, the program runs exact
meet-in-the-middle in $2^{n/2}\mathrm{poly}(n+b+2)$ time.
\item \textbf{Address space (6.3).} If the operation count is $K_02^{cn}(n+b+2)^K$ with $c < 1$, then every address fits in a
word of $w$ bits for large $n$.
\end{itemize}

\subsection*{B.5 The numerical method (paper, Appendix A)}

\begin{itemize}
\item \textbf{Identities (A.2).} With $\mathcal P(x) = \int F(x+w)G(w)\,dw$, $\mathcal Y(x) = \int F(x+w)G(w)(r(x+w) + s(w))\,dw$,
$L = \log Q = \log\mathcal P - \log(Z_fZ_g)$, $B = \mathcal Y/\mathcal P - \log(Z_fZ_g)$ and
$H = \log Z_{f,\kappa} + \log Z_{g,\kappa} - \kappa\log(Z_fZ_g)$, where $Z_f = \int F$, $Z_{f,\kappa} = \int F^\kappa$ and so on:
\[D = B - L,\qquad u = L + (\kappa - 1)B - H,\qquad v = (2 - \kappa)B - 2L + H.\]
\item \textbf{Trapezoid bound (A.6).} If a $2\pi$-periodic $h$ is analytic on a neighborhood of the strip $|\mathrm{Im}\,z| \le \sigma$
and $|h| \le B_0$ there, then the mean of $h$ at $N$ equally spaced nodes differs from $\int h$ by at most
$2B_0/(e^{N\sigma} - 1)$. (The paper states it for $N = 64$; the proof is the same for every $N$.)
\item \textbf{Strip bounds (A.4).} $\int|f(w + iy)|^2\,dw$ is nondecreasing in $|y|$, and equals $Z_f^{-2}\int2^{2r_y}$, where $r_y$
has coefficients $r_j\cosh(jy)$. For $|y| \le 2\beta$, $Q(x + iy) = \int f(x + w + iy/2)\,g(w - iy/2)\,dw$, and
Cauchy--Schwarz gives $|Q - 1| \le \sqrt{(A_f - 1)(A_g - 1)}$ with $A_f = \int|f(\cdot + i\beta)|^2$ and $A_g$ likewise.
The same split gives $|QB| \le \sqrt{A_fA_g}\,\big(\sup_{|\mathrm{Im}| \le \beta}|r| + \sup_{|\mathrm{Im}|\le\beta}|s| + |\log(Z_fZ_g)|\big)$.
\end{itemize}

\subsection*{D.1 The alias constraints}

\begin{lstlisting}
"""Rigorous check (Arb) of the alias-step constraints for the big-block design with value classes of right masks.
Exponents per n; worst case over all deficiency profiles with f(1/2) <= 1/2 - tau0 (else the preliminary search wins).
- 2^F repeated trials, F = -log2 E_V 2^{-d(V)} over (m-2k)-subsets V of M, so F <= d(M) and F <= 1/2 - tau0.
- Right masks Y are grouped by (b^F(Y), c^F(Y)); at most (2m+1) 2^{m - d(M)} classes, so the right list over all trials
  is at most r + (1 - gamma) mu.  The left side pays with d(L) >= F, which needs l >= mu(1-2a).
Usage: python verify_alias_bigclass.py params.json"""
from flint import arb, ctx
import json, sys
ctx.prec = 200
P = json.load(open(sys.argv[1]))
Q = lambda x: arb(str(x))
tau0, eta, a, mu, gam, l = Q(P["tau0"]), Q(P["eta"]), Q(P["a"]), Q(P["mu"]), Q(P["gamma"]), Q(P["l"])
r = 1 - mu - l
def h(x): return -(x*x.log() + (1-x)*(1-x).log())/arb(2).log()
half = Q("0.5"); v = mu*(1 - 2*a); Fmax = half - tau0
log2_3 = arb(3).log()/arb(2).log()
vals = {
  "h(2a)/2": h(2*a)/2,
  "left list": l + (h(a) - gam)*mu,
  "right classes": r + (1 - gam)*mu,
  "pairs": 1 - mu + (h(a) + h(half - a) - gam)*mu - eta,
  "right masks, all trials": h(half - a)*mu + Fmax,
  "left masks, all trials": h(a)*mu + Fmax,
  "(mu/2) log2 3": (mu/2)*log2_3, "v": v, "l": l, "r": r}
checks = {
  "coverage: gamma < h(2a)/2": gam < h(2*a)/2,
  "left list:  l + (h(a) - gamma) mu < tau0": vals["left list"] < tau0,
  "right classes: r + (1 - gamma) mu < tau0": vals["right classes"] < tau0,
  "pairs: 1 - mu + (h(a)+h(1/2-a)-gamma) mu - eta < tau0": vals["pairs"] < tau0,
  "right masks in every trial: h(1/2-a) mu + (1/2 - tau0) < tau0": vals["right masks, all trials"] < tau0,
  "left masks in every trial: h(a) mu + (1/2 - tau0) < tau0": vals["left masks, all trials"] < tau0,
  "value maps of L and R: l, r < tau0": (l < tau0) and (r < tau0) and (r > 0),
  "left side pays the trials: l > mu(1-2a)": l > v,
  "reduction mod P on half blocks: (mu/2) log2 3 < eta": vals["(mu/2) log2 3"] < eta,
  "sampled set fits in half the input: mu(1-2a) <= 1/2": v <= half,
}
for k, x in vals.items(): print(f"{k:24s} {x.str(8)}")
ok = True
for k, c in checks.items():
    print(("PASS " if c else "FAIL ") + k); ok &= bool(c)
slacks = [h(2*a)/2 - gam, tau0 - vals["left list"], tau0 - vals["right classes"], tau0 - vals["pairs"],
          tau0 - vals["right masks, all trials"], l - v, eta - vals["(mu/2) log2 3"]]
eps0 = min(x.lower() for x in slacks)
print(f"least slack eps0 >= {eps0.str(5)} (lower end of the Arb balls)")

\subsection*{D.2 The 430 region integrals}

\begin{lstlisting}
"""Rigorous certificate (Arb ball arithmetic) for a FAMILY of checksum filters chosen per pattern.

For every filter v and every region of patterns assigned to v (case 1, or a band of W in case 2), the JSON lists
multipliers z >= 0 (z[0] is the Chernoff exponent c) and the rows G of the domination inequality:
  case 1:            G = [Delta - u_v, Gamma - w_v, u_v - u_l (l in cons)]
  band [lo, hi):     G = [a w_v - u_v, w_v - Gamma lo, Gamma hi - w_v (if hi), u_v - u_l (l in cons)]
We prove   int M(x)^2 2^{z . G(x)} dx < 2^eta   (normalised circle integral) for every listed certificate.

Method: the paper's Appendix A, as in verify_moments_gen.py.  Inner convolutions are evaluated exactly at N nodes
with Arb polynomial products; trapezoid errors use analytic-strip bounds.  On the outer strip |Im x| <= 2 beta,
|Re u| <= U* and |Re w| <= W* follow from the Cauchy-Schwarz bounds on Q and QB, which bounds Re(z . G)."""
from flint import arb, arb_poly, ctx
import json, sys, time
ctx.prec = 200
A = arb
P = json.load(open(sys.argv[1]))
tau, eta = A(str(P["tau0"])), A(str(P["eta"]))
Delta = eta - tau; Gamma = 2*tau - eta; aG = Delta/Gamma
N = int(P.get("N", 1024)); sig, beta = A(str(P.get("sig", "0.45"))), A(str(P.get("beta", "0.19")))
pi, ln2 = A.pi(), A(2).log()
pow2 = lambda t: (t*ln2).exp()
log2 = lambda t: t.log()/ln2
xs = [2*pi*k/N for k in range(N)]
def trap_err(B0, width): return 2*B0/((A(N)*width).exp() - 1)
def ball(x, err): return x + A(0, err.upper())
def abs_sum(coef, y): return sum(abs(coef[j])*(A(j+1)*y).cosh() for j in range(len(coef)))
mean = lambda v: sum(v)/N
COS = {}
def cosj(j):
    if j not in COS: COS[j] = [(A(j)*x).cos() for x in xs]
    return COS[j]
def trig_nodes(coef): return [sum(coef[j]*cosj(j+1)[k] for j in range(len(coef))) for k in range(N)]
def corr(Fv, Gv):
    """c[j] = (1/N) sum_i F[(i+j) mod N] G[i], via one polynomial product."""
    pa = arb_poly(Fv)
    b = [A(0)]*(N + 1)
    for i in range(N): b[N - i] = Gv[i]
    pr = pa*arb_poly(b)
    co = [pr[t] for t in range(2*N)]
    return [(co[N + j] + co[j])/N for j in range(N)]

def filter_data(fp):
    r = [A(str(x)) for x in fp["r_coef"]]; s = [A(str(x)) for x in fp["s_coef"]]; kappa = A(str(fp["kappa"]))
    rk, sk = trig_nodes(r), trig_nodes(s)
    F = [pow2(t) for t in rk]; G = [pow2(t) for t in sk]
    Rs, Ss = abs_sum(r, sig), abs_sum(s, sig)
    Zf = ball(mean(F), trap_err(pow2(Rs), sig)); Zg = ball(mean(G), trap_err(pow2(Ss), sig))
    Zfk = ball(mean([pow2(kappa*t) for t in rk]), trap_err(pow2(kappa*Rs), sig))
    Zgk = ball(mean([pow2(kappa*t) for t in sk]), trap_err(pow2(kappa*Ss), sig))
    LZ = log2(Zf*Zg); H = log2(Zfk) + log2(Zgk) - kappa*LZ
    eP = trap_err(pow2(Rs + Ss), sig); eY = trap_err(pow2(Rs + Ss)*(Rs + Ss), sig)
    Pc = corr(F, G)
    Yc1 = corr([F[k]*rk[k] for k in range(N)], G); Yc2 = corr(F, [G[k]*sk[k] for k in range(N)])
    u, w = [], []
    for j in range(N):
        Pj = ball(Pc[j], eP); Yj = ball(Yc1[j] + Yc2[j], eY)
        L = log2(Pj) - LZ; B = Yj/Pj - LZ
        u.append(L + (kappa - 1)*B - H); w.append((2 - kappa)*B - 2*L + H)
    # outer strip bounds (|Im x| <= 2 beta)
    rb = [r[j]*(A(j+1)*beta).cosh() for j in range(len(r))]; sb = [s[j]*(A(j+1)*beta).cosh() for j in range(len(s))]
    Ir = ball(mean([pow2(2*t) for t in trig_nodes(rb)]), trap_err(pow2(2*abs_sum(rb, sig)), sig))
    Is = ball(mean([pow2(2*t) for t in trig_nodes(sb)]), trap_err(pow2(2*abs_sum(sb, sig)), sig))
    Af, Ag = Ir/(Zf*Zf), Is/(Zg*Zg)
    q0 = ((Af - 1)*(Ag - 1)).sqrt()
    qb = (Af*Ag).sqrt()*(abs_sum(r, beta) + abs_sum(s, beta) + abs(LZ))
    assert q0 < 1, "q0 >= 1: outer strip too wide"
    Bmax = qb/(1 - q0); lneg = -log2(1 - q0)
    Ustar = lneg + abs(kappa - 1)*Bmax + abs(H)
    Wstar = 2*lneg + abs(2 - kappa)*Bmax + abs(H)
    return dict(u=u, w=w, Ustar=Ustar, Wstar=Wstar, q0=q0)

t0 = time.time()
FD = [filter_data(fp) for fp in P["filters"]]
print(f"{len(FD)} filters, N = {N}, prepared in {time.time() - t0:.0f} s; max q0 = "
      f"{max(float(d['q0'].upper()) for d in FD):.4f}", flush=True)
for i, d in enumerate(FD):
    print(f"  filter {i}: q0 {float(d['q0'].upper()):.4f}  U* {float(d['Ustar'].upper()):.3f}  W* {float(d['Wstar'].upper()):.3f}")
STRIP = [dict(U=float(d['Ustar'].upper()), W=float(d['Wstar'].upper())) for d in FD]
if len(sys.argv) > 2 and sys.argv[2] == "strip":
    json.dump(STRIP, open(sys.argv[1] + ".strip.json", "w")); sys.exit(0)
m2 = [2 + 2*x.cos() for x in xs]; M2s = 2 + 2*(2*beta).cosh(); target = pow2(eta)
worst = None; ok = True
for c in P["certs"]:
    v, z = c["v"], [A(str(t)) for t in c["z"]]; d = FD[v]; cons = c["cons"]
    if c["case"] == "case1":
        rows = [[Delta - d["u"][k], Gamma - d["w"][k]] for k in range(N)]
        sup = [Delta + d["Ustar"], Gamma + d["Wstar"]]
        assert z[0] >= 1
    else:
        lo, hi = A(str(c["lo"])), (A(str(c["hi"])) if c["hi"] is not None else None)
        rows = [[aG*d["w"][k] - d["u"][k], d["w"][k] - Gamma*lo] + ([Gamma*hi - d["w"][k]] if hi is not None else [])
                for k in range(N)]
        sup = [aG*d["Wstar"] + d["Ustar"], d["Wstar"] - Gamma*lo] + ([Gamma*hi + d["Wstar"]] if hi is not None else [])
        assert z[0]*lo >= 1, "Chernoff exponent must be >= alpha <= 1/lo"
    for l in cons:
        for k in range(N): rows[k].append(d["u"][k] - FD[l]["u"][k])
        sup.append(d["Ustar"] + FD[l]["Ustar"])
    assert len(z) == len(rows[0]) and all(t >= 0 for t in z)
    T = mean([m2[k]*pow2(sum(z[i]*rows[k][i] for i in range(len(z)))) for k in range(N)])
    B0exp = sum(z[i]*sup[i] for i in range(len(z)))
    err = trap_err(M2s*pow2(B0exp), 2*beta)
    I = T + A(0, err.upper())
    good = bool(I < target); ok &= good
    marg = eta - log2(I)
    if worst is None or float(marg.lower()) < float(worst[0].lower()): worst = (marg, c)
    print(f"filter {v} {c['case']}{'' if c['case'] == 'case1' else ' ' + str(c['lo'])}: I <= {I.upper().str(10)}"
          f"  log2 margin {marg.str(5)}  (outer err {err.str(3)}) {'PASS' if good else 'FAIL'}", flush=True)
print(f"worst log2 margin {worst[0].str(5)} at filter {worst[1]['v']} {worst[1]['case']}")
print("ALL CERTIFICATES PASS" if ok else "SOME CERTIFICATE FAILS")
\end{lstlisting}
